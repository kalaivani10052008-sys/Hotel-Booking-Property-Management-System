Problem Statement

1. Title

Hotel Booking & Property Management System

2. Domain

Hotel Management

3. Who is the user?

- Customer – Books and manages rooms.
- Admin – Manages hotels, rooms, and bookings.

4. What problem are we solving?

Customers may find it difficult to check room availability and book rooms easily.
Hotel admins may find it difficult to manage rooms and bookings manually.
The system provides a simple online platform to manage hotel bookings and room availability.

5. Proposed Solution

- User registration and login.
- Search hotels and available rooms.
- Book and cancel rooms.
- View booking details.
- Admin can add and manage hotels and rooms.
- Admin can manage bookings and room availability.
- AI can predict room demand.
- Secure login and booking data.

6. Core Entities / Database Tables

1. Users
2. Hotels
3. Rooms
4. Bookings
5. Payments

7. User Roles & Permissions

- Customer: Search, book, cancel, and view bookings.
- Admin: Manage hotels, rooms, prices, and bookings.

8. Success Criteria

- User can find available rooms quickly.
- User can successfully book a room.
- Double booking should be prevented.
- Admin can easily manage rooms and bookings.
- User and booking data should be secure.

9. Out of Scope

- Food ordering.
- Flight booking.
- Hotel staff salary management.
- Loyalty/reward system.

10. Chosen Track

Java – Spring Boot
