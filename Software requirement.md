Software Requirements Analysis
1. Functional Requirements
User can register and login.
User can search for hotels.
User can check room availability.
User can book a room.
User can cancel a booking.
User can view booking details.
Admin can add, update, and delete hotels.
Admin can manage rooms and room availability.
Admin can manage customer bookings.
System stores all booking information in a database.
2. Non-Functional Requirements
Security: Protect user and booking data.
Performance: System should respond quickly.
Reliability: Booking information should be stored correctly.
Usability: Application should be simple and easy to use.
Scalability: System should support more users and hotels in the future.
Availability: Application should be accessible through the cloud.
3. Hardware Requirements
Computer/Laptop
Minimum 4 GB RAM
Internet connection
Smartphone for testing
4. Software Requirements
Frontend: HTML, CSS, JavaScript
Backend: Java Spring Boot
Database: MySQL
IDE: IntelliJ IDEA / Eclipse
Browser: Chrome / Edge
Operating System: Windows/Linux
Cloud: AWS / similar cloud platform
